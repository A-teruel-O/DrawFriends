# DrawFriends

## Resumen
Este proyecto es solo una prueba de la capacidad de github pages, supabase y otras tecnologias gratuitas. 
Es un web donde te unes a una sala con tus amigos y cada dia sale un pokemon de los 151 originales, solo aparece el nombre y tienes que dibujarlo de memoria en 2 minutos, luego de eso se envia y una IA conectada con una API puntua cada dibujo y hace un ranking semanal y total.
Este proyecto es solo por entretenimiento y pensado para un grupo de amigos pequeños, nunca a sido pensado lanzarlo de ninguna manera.
